# Course project datasets

The final project archive supplied code notebooks and a PDF report, but no raw benchmark datasets. The notebooks expect the following data sources/files:

- **Synthetic Gaussian sequences:** generated in the synthetic experiment notebooks.
- **CIC-IDS2017:** `Monday-WorkingHours.pcap_ISCX.csv`, `Tuesday-WorkingHours.pcap_ISCX.csv`, and `Wednesday-workingHours.pcap_ISCX.csv`.
- **Vestas V52:** `normal_operation_moderate_wind_data.csv` and `early_gearbox_bearing_wear_elevated_temp_data.csv`.
- **Continual Wind Energy:** `datasetspart1/train.csv` and `datasetspart1/test.csv`.
- **DNA:** `datasetspart1/train2.csv`.
- **MIT-BIH Arrhythmia:** WFDB records and annotations under `mit-bih-arrhythmia-database-1.0.0/`; the notebook references records 100, 106, and 119.

These datasets are intentionally not included. Obtain them from their original sources, check their licenses and access conditions, and follow each dataset's citation requirements before using or redistributing them.
