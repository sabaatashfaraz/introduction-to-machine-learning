# Homework 2 — Optimization and Constrained Learning

This notebook studies optimization algorithms and constrained optimization through computational experiments.

## Topics
1. **Escaping saddle points:** first-order optimization methods and Newton's method, with execution and visualization.
2. **Armijo–Goldstein line search:** implementing a line-search optimizer and comparing it with a constant learning rate on an ill-conditioned objective.
3. **Multivariate Gaussian KL divergence:** positive-semidefinite covariance parameterization, Cholesky factors, analytical KL divergence, and Adam optimization.
4. **KKT conditions and penalty methods:** analytical Karush–Kuhn–Tucker derivation, exterior penalty objectives, iterative penalty updates, and optimization-trajectory visualization.
