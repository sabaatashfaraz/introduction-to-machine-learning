# Homework 4 data

The original archive contained:
- Breast-cancer splits: `breast_cancer_train.csv`, `breast_cancer_val.csv`, `breast_cancer_test.csv`
- Handwritten-digit splits: `digits_train.npz`, `digits_val.npz`, `digits_test.npz`, plus shifted, noisy, and low-contrast test variants and `manual_digit_8x8.csv`
- Wine splits: `wine_train.csv`, `wine_val.csv`, `wine_test.csv`
- Diabetes GP files: `diabetes_gp_train.csv`, `diabetes_gp_pool.csv`, `diabetes_gp_grid.csv`
- `dataset_metadata.json`

The metadata in the original archive identifies scikit-learn's `load_breast_cancer`, `load_digits`, `load_wine`, and `load_diabetes` as the source datasets. The preprocessed split files are not bundled here. Regenerate equivalent inputs from the documented source datasets or obtain the course-provided files through authorized channels.
