# Homework 5 — Dimensionality Reduction and Clustering

This notebook applies unsupervised learning to credit-card customer data.

## Topics
- Data preprocessing and handling missing or unsuitable fields.
- Feature standardization.
- Principal Component Analysis (PCA).
- Cumulative explained-variance analysis and dimensionality selection.
- K-Means clustering and the elbow method.
- Hierarchical clustering and dendrogram-based analysis.
- Comparing clustering before and after dimensionality reduction.
