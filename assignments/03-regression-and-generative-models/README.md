# Homework 3 — Regression, Discriminant Analysis, and Generative Models

This notebook moves from regression to probabilistic classification and generative modeling.

## Topics
- Simple and multiple linear regression.
- Gradient-descent implementation.
- Ridge (L2) and Lasso (L1) regularization.
- Linear Discriminant Analysis (LDA) and Quadratic Discriminant Analysis (QDA).
- Robustness to noise.
- Generative modeling and quantitative evaluation using KL divergence and moment matching.
- Heteroskedastic regression.
- Overfitting and weight-amplitude analysis.
- Bayesian inverse problems.
